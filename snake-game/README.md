Snake Game
===========

A minimal classic Snake game demo using HTML5 Canvas and JavaScript.

Run locally:
1. Open `index.html` in your browser.

Or serve with a simple static server (recommended for some browsers):

```powershell
# Python 3
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Controls: Arrow keys or WASD. Click "Restart" to play again.
